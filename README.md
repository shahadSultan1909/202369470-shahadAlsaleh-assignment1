# Shahad Sultan Alsaleh — Personal Portfolio (Assignment 1)

## Project Description

This is a simple, responsive personal portfolio website built as the
foundation for my professional portfolio. It introduces me as a Computer
Science student, showcases three of my technical projects, and provides a
contact form for visitors to reach out.

The site is built using only **HTML, CSS, and JavaScript** — no frameworks
or backend

### Sections
- **About Me** — a short introduction, background, skills, and hobbies.
- **Achievements** — academic honors and test scores.
- **Projects** — three featured projects with descriptions and GitHub links.
- **Contact** — a form (Name, Email, Message) with client-side validation.

### Features
- Fully responsive layout (desktop, tablet, mobile) using CSS Flexbox/Grid.
- Smooth scrolling navigation between sections.
- Time-of-day greeting message on the homepage.
- Client-side contact form validation (no backend required).
- Mobile hamburger navigation menu.

## Setup Instructions (Run Locally)

No installation or build tools are required — this is a static website.

1. **Clone or download** this repository:
```bash
   git clone https://github.com/shahad1233/202369470-shahadAlsaleh-assignment1.git
```
2. **Navigate** into the project folder:
```bash
   cd 202369470-shahadAlsaleh-assignment1
```
3. **Open `index.html`** directly in your browser:
   - Double-click the file, **or**
   - Right-click, then click "Open with", lastly choose your preferred browser, **or**
   - Use the VS Code "Live Server" extension for auto-reload while editing.
